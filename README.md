# STOQ

React, TypeScript, Vite, Mantine, Redux Toolkit и React Router.

Запуск: `npm install`, затем `npm run dev`.

Десктопное приложение (Electron):

- `npm run desktop:dev` — запускает Vite на `127.0.0.1:5174` и открывает окно STOQ. При закрытии окна Vite тоже останавливается.
- `npm run desktop:build` — собирает сайт и Windows-установщик x64. Результат: `release/STOQ-<версия>-Setup.exe`; приложение без установки: `release/win-unpacked/STOQ.exe`.

Сборка открывает локальные файлы через `stoq://app`, сохраняя BrowserRouter и прямые переходы на вложенные страницы. Интерфейс работает без Node.js; в Electron не добавлен доступ к файловой системе из React. Установщик пока без цифровой подписи.

Иконки окна и установщика автоматически создаются из `public/favicon.svg` в PNG/ICO при запуске десктопных команд. Верхняя панель имеет цвет `#002A2D` и сохраняет стандартные кнопки управления окном.

Адрес API задаётся в `.env` через `VITE_API_URL` до сборки. Для запросов из установленного приложения бэкенд должен разрешать origin `stoq://app` в CORS. Для QR и приглашений гостям нужен публичный адрес сайта в `VITE_PUBLIC_SITE_URL`; локальный адрес десктопного приложения не является публичной ссылкой.

Архитектура и подключение бэкенда описаны в [ARCHITECTURE.md](./ARCHITECTURE.md).

- `npm run build` — проверка типов и production-сборка.
- `npm test` — доменные расчёты, экспорт, границы FSD и отсутствие локального сохранения моков.
- `npm run test:architecture` — архитектурные ограничения и заглушки запросов.

Данные читаются из `entities/*/model/mock.ts` через публичные API сущностей. Серверные действия пока являются заглушками с `//!`; поиск, навигация, ввод черновиков, корзина, QR и локальный экспорт XLSX работают в интерфейсе.
