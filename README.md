# STOQ — система управления рестораном

**STOQ** — экосистема для автоматизации ресторанного бизнеса. Объединяет управление складом, поставками, меню, заказами и аналитикой в единой системе.

🌐 **[Демо](https://lyaguh.site/)**

## 🛠 Технологический стек

- **React+ TypeScript**
- **Vite**
- **Mantine UI**
- **Redux Toolkit / RTK Query**
- **React Router**
- **Socket.IO**
- **Recharts / Mantine Charts**
- **React Flow + D3**
- **Electron**

## 💻 Локальный запуск

**Требования:** Node.js и npm.

```bash
git clone https://github.com/MissClickRND/stoq-frontend.git
cd stoq-frontend
npm install
```

Создайте `.env` на основе `.env.example` и настройте подключение к backend.

```env
VITE_API_URL=http://localhost:3000
VITE_WEBSOCKET_API_URL=ws://localhost:3000
```

Для локального фронта с production backend:

```env
API_PROXY_TARGET=https://lyaguh.site/api
VITE_WEBSOCKET_API_URL=wss://lyaguh.site
```

После изменения `.env` перезапустите Vite. Путь `/api` обязателен для публичного
адреса: без него nginx отдаёт HTML приложения вместо ответа API. Для прямого
локального gateway на порту 3000 используйте URL без `/api`.

Запустите приложение:

```bash
npm run dev
```

### Desktop-версия

```bash
npm run desktop:dev
```

Сборка установщика Windows:

```bash
npm run desktop:build
```

## 🔗 Архитектура

Frontend взаимодействует с backend через REST API и Socket.IO.

Система поддерживает работу с сервисами каталога, склада, заказов, аналитики и рекомендаций. Бизнес-логика расчёта цен, доступности блюд и складских операций выполняется на сервере.
