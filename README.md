# STOQ — система управления рестораном

**STOQ** — экосистема для автоматизации ресторанного бизнеса. Объединяет управление складом, поставками, меню, заказами и аналитикой в единой системе.

🌐 **[Демо](https://lyaguh.site/)**

## 🛠 Технологический стек

- **React+ TypeScript**
- **Vite**
- **Mantine UI**
- **Redux Toolkit / RTK Query**
- **React Router**
- **Socket.IO**
- **Recharts / Mantine Charts**
- **React Flow + D3**
- **Electron**

## 🚀 Функционал

### 📊 Дашборд и аналитика

- Краткая наглядная статистика
- Графики выручки, прибыли, заказов и блюд
- Мониторинг остатков и сроков годности

### 📦 Складской учёт

- Управление продуктами и складскими партиями
- Обновление информации в реальном времени через websockets
- Контроль количества и сроков годности
- Списание продуктов с историей движений
- Отслеживание низких остатков
- Автоматическое обновление складских данных
- Возможность провести инвентаризацию

### 🚚 Поставки

- Создание и редактирование поставок
- Управление статусами поставок с подробным просмотром
- Приёмка товаров на склад
- **AI-распознавание УПД** по изображению или PDF
- Автоматическое заполнение данных из документов
- Возможность интеграции сервиса со сторонним API

### 🍽 Меню и блюда

- Управление каталогом блюд и ингредиентов
- Контроль доступности блюд по остаткам
- Стоп-лист недоступных позиций
- Рекомендации и горячие предложения с подробной аналитикой
- Интерактивный граф зависимостей блюд и ингредиентов

### 🛒 Заказы и гостевое меню

- Детальная таблица заказов
- Просмотр меню с поиском и пагинацией
- Корзина и оформление заказов
- Учёт столов, гостей и количества блюд
- Подтверждение и просмотр созданных заказов
- Автоматический расчёт стоимости на сервере
- Отображение рекомендованных блюд

### ⚙️ Дополнительно

- Полная экосистема с Мобильным, Desktop, Web-приложениями и Telegram ботом
- Авторизация пользователей
- Обновления и уведомления через WebSocket
- Тестовая панель с демоданными
- Адаптивный интерфейс
- Desktop-приложение для Windows

## 💻 Локальный запуск

**Требования:** Node.js и npm.

```bash
git clone https://github.com/MissClickRND/stoq-frontend.git
cd stoq-frontend
npm install
```

Создайте `.env` на основе `.env.example` и настройте подключение к backend.

```env
VITE_API_URL=http://localhost:3000
VITE_WEBSOCKET_API_URL=ws://localhost:3000
```

Запустите приложение:

```bash
npm run dev
```

### Desktop-версия

```bash
npm run desktop:dev
```

Сборка установщика Windows:

```bash
npm run desktop:build
```
