# Аналитика

Раздел `/analytics` открывает карту зависимостей. Вкладки ведут на отдельные маршруты:

- `/analytics/dashboard` — дашборд (пока заглушка).
- `/analytics/ingredients` — анализ ингредиентов (пока заглушка).
- `/analytics/dependencies` — свободный граф ингредиентов и блюд.

Старый `/dashboard` перенаправляет на `/analytics/dashboard`.

## Данные карты

DTO и мок находятся в `src/entities/dependency-graph/model/type.ts` и `mock.ts`. Чтение идёт через `useDependencyGraph` из публичного API сущности. Место будущего запроса отмечено `//!` в `api/dependencyGraph.ts`.

Ответ содержит `nodes` и `edges`, без координат. ID сохраняются без изменений. Узлы ингредиентов имеют `type: "ingredient"`, имя, остаток, единицу и статус `available`, `low_stock` или `out_of_stock`. Узлы блюд имеют `type: "dish"`, имя и статус `available`, `low_stock` или `unavailable`.

Связь направлена от ингредиента к блюду; `data` содержит `required`, `unit` и статус. Цвет связи определяется её серверным статусом: `available` — зелёный, `low_stock` — оранжевый, `unavailable` — красный. Клиент не пересчитывает доступность из остатков: нормы и пороги остаются ответственностью бэкенда.

## Отображение

Все страницы собраны через `DefaultPageLayout`; навигация передаётся в его `topSection`.

Виджет `src/widgets/dependency-graph` вычисляет стабильную раскладку через `d3-force`, затем устраняет перекрытия карточек и подписей с зазором 56 px. Дополнительный шаг меняет местами узлы одного типа, если это уменьшает пересечения прямых между их центрами. Он сохраняет зазоры, но не гарантирует отсутствие пересечений кривых линий. ReactFlow отвечает за полотно, масштаб, перемещение камеры и узлов.

Ингредиенты отображаются точками с подписями и остатками, блюда — прямоугольными карточками. Поиск закреплён поверх карты справа сверху. Он приближает найденные узлы вместе с непосредственными соседями; наведение и фокус клавиатуры подсвечивают связи без всплывающих подсказок. Узлы можно перетаскивать; связи следуют за ними. Координаты хранятся в локальном состоянии виджета и сбрасываются при повторном открытии страницы. Соединять и удалять узлы нельзя; серверные данные и моки не изменяются.

Проверка раскладки: `npm run test:analytics`. Общие проверки: `npm test` и `npm run build`.
